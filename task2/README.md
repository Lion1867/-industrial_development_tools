# task2

Три скрипта на bash:

- `find_files.sh dir ext min_size` - ищет файлы с расширением ext размером от min_size (можно 500, 5K, 2M) и выводит размер, дату изменения и путь, сортировка по размеру
- `organize.sh dir` - раскладывает файлы из папки по images/, archives/, documents/ и other/. Если файл с таким именем уже есть, к новому добавляется _1, _2 и т.д.
- `find_dups.sh dir` - ищет одинаковые файлы по sha256, выводит группы и сколько места можно освободить

Данные лежат в data/ в архивах. `./demo.sh` распаковывает их в demo/ и запускает все три скрипта.

Пример:

```
$ ./find_files.sh demo/01 txt 1K
20480	2026-10-01 19:10	demo/01/files/sub/c.txt
5120	2026-10-01 19:10	demo/01/files/b.txt
```
