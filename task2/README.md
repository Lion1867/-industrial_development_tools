# Задание 2. Bash-скрипты для работы с файлами

Все скрипты начинаются с `set -euo pipefail` и проверяют аргументы.

| № | Скрипт | Задача | Инструменты |
|---|--------|--------|-------------|
| 1 | `find_files.sh` | Умный поиск файлов | `find`, `-size`, `-printf`, `sort`, `$1..$3` |
| 2 | `organize.sh` | Организатор Downloads | `case`, glob, `mv`, проверка `-e` |
| 3 | `find_dups.sh` | Поиск дубликатов | `find`, `sha256sum`, `awk`, `declare -A` |
| — | `demo.sh` | Прогон всех задач на данных из `data/` | |

## Подготовка

```bash
chmod +x *.sh
./demo.sh          # распакует data/*.zip в demo/ и покажет все три задачи
```

## 1. Умный поиск файлов

```bash
./find_files.sh <каталог> <расширение> <мин_размер>   # размер: 500, 5K, 2M, 1G
./find_files.sh demo/01 txt 1K
```
```
РАЗМЕР(Б)   ИЗМЕНЁН              ПУТЬ
20480       2026-10-01 19:10:46  demo/01/files/sub/c.txt
5120        2026-10-01 19:10:46  demo/01/files/b.txt
```
Как работает: размер переводится в байты, затем
`find -type f -iname "*.ext" -size +Nc -printf '%s\t%T…\t%p\n' | sort -nr` —
файлы не меньше заданного размера, отсортированные по убыванию размера.

## 2. Организатор Downloads

```bash
./organize.sh <каталог>
```
- изображения (jpg, png, gif…) → `images/`
- архивы (zip, tar, gz, 7z…) → `archives/`
- документы (pdf, docx, txt, xlsx…) → `documents/`
- остальное → `other/`

Расширение сравнивается без учёта регистра (`photo.JPG` → `images/`).
Если файл с таким именем уже есть в папке назначения (`[[ -e ... ]]`),
новый получает суффикс: `photo.JPG` → `photo_1.JPG`. Ничего не перезаписывается.

```
photo.JPG -> images/photo.JPG
report.pdf -> documents/report.pdf
...
photo.JPG -> images/photo_1.JPG     # повторный прогон с тем же именем
```

## 3. Поиск дубликатов

```bash
./find_dups.sh <каталог>
```
Для каждого файла считается `sha256sum`; в ассоциативных массивах
(`declare -A`) копятся пути, количество и размер по каждому хешу.
Группа с ≥2 файлами — дубликаты; освобождаемое место = размер × (копий − 1).

```
Группа 1: 3 файла(ов) по 20480 Б, sha256=92c9f7fb9867…, можно освободить 40960 Б
    demo/01/files/sub/c.txt
    demo/01/files/c_old.txt
    demo/01/c_backup.txt
Группа 2: 2 файла(ов) по 5120 Б, sha256=e8e4156fbd66…, можно освободить 5120 Б
    demo/01/files/b.txt
    demo/01/files/sub/b copy.txt
Итого групп: 2, можно освободить: 46080 Б (45K)
```
